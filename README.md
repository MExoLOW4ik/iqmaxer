# iQmaxer 🎯 — Friendly Tutor & Life RPG

> **Преврати любую цель в систему квестов.**
> Напиши цель — AI сгенерит «лююютый план» с ежедневными/месячными/годовыми заданиями.
> Выполняешь → получаешь XP → повышаешь ранг E→D→C→B→A→S.

## Как работает

```
Ты → пишешь цель → AI → план с квестами
       ↓
     Ежедневные задания
       ↓
     Выполнил → XP + Level Up + ачивки
       ↓
     Новый ранг → новые возможности
```

## Фичи

- **Цели любого масштаба:** выучить матчасть, прокачать руки, накопить, написать книгу
- **Иерархия квестов:** годовые → месячные → ежедневные с дедлайнами
- **Ранговая система:** E (легко) → D → C → B → A → S (брутально)
- **Система уровней:** XP фармится за выполненные задания
- **Streak бонус:** чем длиннее серия, тем больше XP (×1.0 → ×5.0)
- **Ачивки:** First Steps, Dedicated, Scholar, Grinder и другие
- **AI-тьютор:** дружелюбный профессор ведёт диалогом — объясняет, спрашивает, направляет
- **Дружелюбный UI:** тёплая тема, мягкое свечение, Level Up анимация

## Технологии

| Компонент | Технология |
|-----------|-----------|
| Backend | Python FastAPI |
| Frontend | HTML + CSS + JS (SPA) |
| AI | OpenRouter (GPT-4o / Claude) |
| БД | SQLite |
| Прокси | nginx |

## Установка

```bash
git clone git@github.com:MExoLOW4ik/iqmaxer.git
cd iqmaxer

# Backend
cd backend
pip install -r ../requirements.txt
python3 -m uvicorn main:app --host 0.0.0.0 --port 8100
```

Для AI-генерации планов (без неё — fallback с базовыми квестами):
```bash
export OPENROUTER_API_KEY=sk-or-v1-...
```

## API

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/user` | GET | Статистика пользователя |
| `/api/goals` | GET | Все цели |
| `/api/goals/{id}` | GET | Цель + квесты |
| `/api/goals` | POST | Создать цель (AI генерит план) |
| `/api/quests/{id}` | PATCH | Завершить квест |
| `/api/daily` | GET | Квесты на сегодня |
| `/api/history` | GET | История выполненных |
| `/api/achievements` | GET | Все ачивки |
